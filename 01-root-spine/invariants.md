# Invariants — rules that never change

1. The OS is files. Markdown, YAML, SQLite — portable and yours.
2. Nothing ships past the autonomy level set in company.yaml.
3. Every agent run is logged. No silent actions.
4. Memory is loaded before every task.
5. All paths relative to repo root. Cross-platform always.
6. Secrets live in .env only. Never committed.
