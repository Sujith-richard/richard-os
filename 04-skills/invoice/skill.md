# Skill: Invoice Generation

## When to use
- Freelance work completed / milestone reached

## Process
1. Pull the client from CRM (contact + company)
2. Pull the project value from PM
3. Generate invoice: client, date, line items, total, payment terms
4. Log in finance DB as "invoice sent" (autonomy 2 — approval before send)

## Format
Plain text / markdown invoice — free, portable, cross-platform.
