# Skill: Resume Tailoring

## When to use
- Before applying to any role

## Process
1. Read the job description
2. Read the OS memory (skills, projects, achievements)
3. Extract required keywords & skills
4. Rewrite bullet points to match the role, with measurable impact
5. Keep it one page, ATS-friendly

## Evidence
- Store the matched keywords + the tailored bullet points in the run log
- Never invent experience — only rephrase real work
